## Scope and status

The repository is read-only between maintenance changes. Its current tree closely matches veloriavault-headless-v2. Review histories, deployment references, WooCommerce configuration, and license differences before consolidating any archive.

## Inspect the source

The repository’s default branch is the source of truth for the files currently available. Inspect [history](https://github.com/ak1458/veloriavault-web-nextjs/commits) to understand changes over time. Do not treat an archive label as a build or runtime validation.

Top-level source areas: `docs/`, `public/`, `src/`.

## Setup and versions

No new binary release or registry package is published by this documentation update. For historical reproduction, review the checked-in manifest and environment requirements first, use an isolated database, and keep production credentials out of the checkout. A dependency install is not proof that old integrations still work.
